## General CS variants

Systems: `architecture -> scheduling/control mechanism -> implementation details -> operational trade-offs`

Security: `threat/assumption model -> analysis or repair mechanism -> enforcement or audit workflow -> safety limitations`

PL: `language core -> judgment/rule/invariant -> algorithm -> soundness or precision argument`

Theory: `model -> definitions -> algorithm or construction -> lemma sequence -> theorem statement`

HCI: `design goals -> interface/prototype -> procedure -> analysis plan`

Measurement: `data sources -> collection method -> cleaning/linking -> validation -> bias checks`
