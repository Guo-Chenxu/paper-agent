# Method Pre-Writing Questions

`Before writing Method, answer what contribution units exist and, for each unit, what mechanism it uses, why it is needed, and why readers should believe it supports the paper's claims.`

```text
Questions:
(1) What are the contribution units in the approach?
(2) For each contribution unit, answer four questions:
    - What input/artifact/problem state does it receive?
    - What mechanism does it apply?
    - What output/property/decision does it produce?
    - Why is this unit needed for the paper's claim?
```

Recommended action:

1. Organize answers in a table before writing paragraphs.
2. Use one row per system component, analysis rule, proof lemma, study procedure, interface element, or measurement step.
3. Delete any row whose output is not used by later sections or evaluation claims.
