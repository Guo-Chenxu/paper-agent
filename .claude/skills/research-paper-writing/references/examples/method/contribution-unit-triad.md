# Contribution Unit Triad

`Use this file to structure a Method subsection around three elements: motivation, mechanism, and evidence-facing advantage.`

Local source references:

1. Annotated approach notes: `references/examples/method/annotated-approach-example.md`

Triad mapping template:

1. Motivation: what unresolved technical need requires this contribution unit.
2. Mechanism: what artifact is built and how it operates.
3. Evidence-facing advantage: why the mechanism should improve the claim that the evaluation, proof, study, or measurement later tests.

Direct usage:

1. Read `annotated-approach-example.md` to map each paragraph to one triad element.
2. Rebuild your Method subsection with the same logic, adjusting the order when a definition must precede motivation.

## Paragraph pattern

```text
A remaining difficulty is [specific difficulty].
To address it, [unit name] [mechanism in concrete steps].
This design supports [claim] because [reason that later evidence can test].
```
